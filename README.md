# Shopware Extension Webshell

1. zip the folder webshell/ (`zip -r webshell.zip webshell/`) or download the .zip from the [latest release](https://github.com/m10x/Shopware-Extension-Webshell/releases/tag/1.0.0)
2. upload it via the extension manager
3. use it `/webshell?secret=m10x&cmd=id`
